# Каталог інтерактивів — як користуватися

## Один раз налаштувати
1. Завантажте всі файли з архіву в репозиторій (разом із прихованою папкою `.github`).
2. Settings → Actions → General → Workflow permissions → **Read and write permissions** → Save.
3. Settings → Pages → Source: **Deploy from a branch**, гілка `main`, папка `/ (root)`.

## Додати інтерактив, що лежить у цьому репозиторії
У `<head>` файлу інтерактиву допишіть два рядки:
```html
<meta name="klas" content="6">
<meta name="tema" content="Алгоритми">
```
Назва на картці береться з `<title>`. Клас можна вказати кількома: `5,6` або `5-7`.

## Додати інтерактив з іншого місця (інший репозиторій, сайт)
Допишіть рядок у `links.csv`:
```
https://адреса-інтерактиву,8,Тема,Назва
```

## Що далі
Нічого: після кожного збереження (commit) GitHub сам оновить `catalog.json`, і за хвилину-дві каталог покаже нове.
Інтерактиви без `<meta name="klas">` у каталог не потрапляють.
